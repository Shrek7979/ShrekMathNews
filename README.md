수학 교사를 위한 수학 뉴스 릴스. 2시간마다 수학 뉴스·영상·SNS 게시물을 모아 카드로 보여 줍니다.

- 사이트: https://shrek7979.github.io/ShrekMathNews/
- 사용법·구조·소스 추가 방법: [수학릴스-안내.md](수학릴스-안내.md)
- GitHub 처음 쓰는 분: [깃허브-배포-따라하기.md](깃허브-배포-따라하기.md)

npm run local    # 사이트 실행 + 2시간마다 자동 수집 (http://localhost:3000)
